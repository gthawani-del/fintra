# Changes from paper-popup — five decisions
| Parameter | Original | Custom | Reason / status |
|---|---|---|---|
| Palette | Saturated children’s-book colours | Teal, terracotta, mustard, warm cream | Adult everyday story; rendered comparison |
| Typography | Rounded Latin display families | Noto Sans Devanagari + restrained sans | Complete Hindi shaping; rendered |
| Motion intensity | Broad elastic gags | Small hinged gestures and deliberate holds | Understated family performances; motion demonstration pending |
| Voice and sound | Blips / English storyteller demo | Hindi dialogue; dry voices, quiet paper foley | Comprehension first; new voice audition generated |
| Native move emphasis | Many magical mechanisms | Pull-tab reveals source information beside AI draft | Make checking an answer visible; full-film implementation pending |

Unchanged: Three.js engine, real-unit book, cut-paper material, front/back cards, silhouette shadows, keyed macro lens, deterministic render(t). Comparison uses this original scene with base vs custom palette; Hindi font is shared as a glyph-capable stand-in. It is not the upstream demo frame.
