# Woh Lamhe — beach-story film (Lemo-Opuscar)

The original user-supplied audio is used only for the final local mux and is NOT stored in this public repository.

Image sources downloaded at render time under the Unsplash License (https://unsplash.com/license). Photographers own original photographs; the images are not models of any real recurring couple, so shots avoid face-identifying close-ups.

Visual direction: cinematic photographic parallax, multiple distinct beach scenes, reflected shoreline, warm memories versus cool loneliness, lyric highlights. This is a photo-motion composition, NOT footage of people physically walking.

Engine: official Lemo-Opuscar `core/render/video.mjs`, deterministic Canvas `render(t)`, GitHub Actions browser frames. FFmpeg is used for final audio mux and compression only.

Lyrics in `lyrics.json` are draft phrase timings until a verified vocal alignment is completed. Review sync before release.
