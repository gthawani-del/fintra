# Ramayana — material transformation proof
24-second, 1280x720, 24fps music-led look-development test. This is not the revised
full film and does not replace its narration or word-highlighted captions.
Original palace drawing is converted to fixed-seed knife strokes with the actual
upstream Impasto / plate engine. The authored sun-window uses upstream Pass
glass texturing and the WebGL transmitted-light compositor. The ocean is custom
Canvas layered-paper animation with fixed fibres, cast shadows and curled crests;
it is not the upstream 3D lightbox engine. Approved native-generated Hanuman art
is reused as a rigid cutout, not claimed as articulated flying performance.
The material match cuts and bold palette are the subject of this proof.
Upstream engine code is copied unchanged and retains its MIT license.
