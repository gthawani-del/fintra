# Ramayana: The two boons
18-second shadow-theatre segment for the three-style proof. Original custom Indian court puppets and palace are drawn in Canvas, using Lemo's hide-carving toolkit, pinned at bebbbe1aa92a3cb4bb6f83500e61b23a17d1aa00. Rendered through official core/render/video.mjs at 1080p24. Scene uses a Canvas cloth/light approximation, not the upstream multipass WebGL light compositor.

Kaikeyi demands; Dasharatha lowers his hand and head; a foreground column reveals Rama accepting the vow. Original 17–35-second audio excerpt from the approved Ramayana proof is retained with quiet synthesized rod taps and a gong accent. No paid generative-image or generative-video calls.

Use assets/audio.wav (private, excluded) and run LEMO_ROOT=/path/to/lemo bash build.sh. FFmpeg, Noto Sans Devanagari Bold, scipy/numpy and Lemo's browser dependencies required. Captions use original script and ASR-estimated boundaries, with merged tokens split proportionally; exact phoneme alignment is not certified.

Reference: user-supplied 9.47-second illustrated-family screen recording, studied for interaction, layered settings and shot variation only. No reference footage or music is used. Changes from upstream demo: story structure, opening, signature action, camera path, score and ending all differ. This is an Indian adaptation of the shadow-puppetry grammar. Approved bold sans-serif typography supersedes upstream serif defaults.
